# Changelog

## [1.1.0] - 2026-07-26

### What's Changed

#### 🎨 UI/UX Redesign
- **Toolbar**: объединены оконные контролы (свернуть/развернуть/закрыть) и навигационные иконки в единый горизонтальный тулбар высотой 32-36px, как в нативных приложениях
- **Sidebar**: вертикальное меню с логотипом приложения сверху, пункты меню — иконка + подпись в один ряд (Главная, Обзор, Популярное, Коллекции, Закладки, Загрузки), активный пункт с акцентной полосой слева
- **Вкладки**: горизонтальные текстовые вкладки (Аниме, Анонсы, Онгоинги, Фильмы, OVA, Дунхуа, Последнее, Завершённые) с подчёркиванием активной
- **Страница тайтла**: полный экран с кнопкой воспроизведения, выпадающим списком статуса, счётчиком закладок, рейтингом/голосованием, комментариями и связанными релизами

#### ✨ Новые функции
- **Кнопка обновления**: зелёная кнопка «Обновление доступно» загорается автоматически при выходе нового релиза на GitHub (GitHub Releases API polling)
- **Видеоплеер**: поддержка HLS-потоков, скорости воспроизведения 0.5x – 3.0x, качество 1080p/720p/480p/4K (Torrent), режим ИИ-апскейлинга
- **Настройки**: вкладки Аккаунт, Внешний вид (темы, кастомные цвета), Уведомления, Конфиденциальность, Логи активности
- **Режим «Смотреть вместе»**: синхронизация воспроизведения через WebSocket

#### 🐛 Исправления
- Исправлена разметка модального окна настроек (лишние/отсутствующие div-теги)
- Исправлены ошибки компиляции Vite build (JSX синтаксис)
- Исправлено дублирование строк вкладок
